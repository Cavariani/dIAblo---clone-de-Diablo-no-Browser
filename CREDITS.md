# Créditos

Diablopus é um projeto pessoal, não comercial, inspirado na série Diablo (Blizzard Entertainment). **Nenhum asset da Blizzard é usado.** Código, design, textos e UI são originais.

Fonte: projeto **Flare** — https://flarerpg.org · https://github.com/flareteam/flare-game
Licença: Creative Commons Attribution-ShareAlike 3.0 (https://creativecommons.org/licenses/by-sa/3.0/).
